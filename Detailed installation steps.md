This installation document essentially requires you to do four things: clone the GitHub source code, download `data.zip` and put the model/ data into `Server`, create a Conda environment to run `server.py`, and then use the `unity_cell_data.csv` generated by the backend for the Unity front-end.

---

# 一. Unify the installation directory first

I suggest you stick to this directory:

```text
D:\NicheTwin3D
```

Finally, we hope to form this structure:

```text
D:\NicheTwin3D
├─ Source        ← GitHub Source code
│  └─ Server     ← Python Backend directory
├─ App           ← Windows Front-end programs
│  └─ NicheTwin3D
│     ├─ NicheTwin3D.exe
│     └─ NicheTwin3D_Data
│        └─ StreamingAssets
└─ Downloads     ← Temporarily set aside data.zip、NicheTwin3D_Windows.zip
```

Do not place it in:

```text
C:\Program Files
Chinese desktop paths with many spaces
```

These paths can easily cause problems due to permissions, Chinese paths or spaces.

# 十、InstallPyTorch

Make sure the command line has the following at the front:

```text
(aivc)
```

Then upgrade the pip first:

```bat

```

Then run the PyTorch command in the installation documentation:

```bat
pip install torch==2.1.0+cu118 torchvision==0.16.0+cu118 torchtext==0.16.0+cpu --extra-index-url https://download.pytorch.org/whl/cu118
```

This step involves installing PyTorch on CUDA version 11.8. The official old PyTorch version page also lists the installation methods for CUDA 11.8 for 'torch==2.1.0' and 'torchvision==0.16.0'.([pytorch.org](https://pytorch.org/get-started/previous-versions/))

Inspection after installation:

```bat
python -c "import torch; print(torch.__version__); print(torch.cuda.is_available())"
```

Ideal damage output is similar:

```text
2.1.0+cu118
True
```

Meaning:

```text
2.1.0+cu118  ← PyTorch CUDA 11.8 Installation successful
True         ← Detected availability NVIDIA GPU
```

If the output is:

```text
False
```

This indicates that Python currently does not detect available CUDA GPUs. Common reasons include missing NVIDIA graphics cards, unsuitable graphics drivers, or computers using integrated graphics/AMD graphics cards. You can try the following steps first, but AI inference related features may be affected.

If this step is incorrect:

```text

```

First, make sure you are:

```text
(aivc)
```

Confirm Python is 3.9:

```bat
python --version
```

Then try again:

```bat
python -m pip install --upgrade pip
pip install torch==2.1.0+cu118 torchvision==0.16.0+cu118 --index-url https://download.pytorch.org/whl/cu118
```

# 十二、Launch the Python backend

Don't just use the original text:

```bat
python server.py
```

I recommend using the following command because it can directly output 'unity_cell_data.csv' to the correct directory in the Unity frontend:

```bat
python server.py --output_dir "D:\NicheTwin3D\App\NicheTwin3D\NicheTwin3D_Data\StreamingAssets"
```

In the source code, the '--output_dir' specification specifies the absolute path to 'StreamingAssets' packaged by Unity; If not specified, the program will revert to the default relative path.([github.com](https://github.com/123-wang-en-ci/NicheTwin3D/blob/main/Server/server.py))

After launching, you may see information like:

```text
[System] Initialize Nicheformer engine.....
[LifeSpan] Server starting up...
[Backend] Loading data: Allen2022Molecular_lps_MsBrainAgingSpatialDonor_14_1.h5ad .....
[Sync] Generate CSV for Unity ...
[Successfully] CSV saved to: D:\NicheTwin3D\App\NicheTwin3D\NicheTwin3D_Data\StreamingAssets\unity_cell_data.csv
Uvicorn running on http://127.0.0.1:8000
```

The source code also uses 'uvicorn.run(app, host="127.0.0.1", port=8000)' to start the backend, so the backend service address is the local '127.0.0.1:8000'.([github.com](https://github.com/123-wang-en-ci/NicheTwin3D/blob/main/Server/server.py))

Important: **Don't close this window. **

That is the backend server. If you close it, the backend features in the Unity frontend will fail.

# 十八、Common problem troubleshooting

## 1. `conda` is not an internal or external command

You might be opening a regular CMD.  Please open it from the Start menu:

```text
Anaconda Prompt
```

instead of:

```text
Command Prompt
PowerShell
Windows Terminal
```

## 2. `git` is not an internal or external command

Git wasn't installed properly, or after installing Git, you didn't reopen Anaconda Prompt.  Treatment:

```text
Reinstall Git for Windows
Close current Anaconda Prompt
Reopen Anaconda Prompt
Then enter it git --version
```

---

```bat
dir environment.yml
```

```text
D:\NicheTwin3D\Source\Server
```

---

## 4. Backend prompt cannot be found `.h5ad`

If you see something like:

```text
Error: File not found D:\NicheTwin3D\Source\Server\Allen2022Molecular_lps_MsBrainAgingSpatialDonor_14_1.h5ad
```

```text

```

不是：

```text

```

If it's in another folder, copy it to the `Server` directory.

---

## 6. `torch.cuda.is_available()` 显示 `False`

这通常说明没有检测到可用 NVIDIA GPU。PyTorch 官方默认不支持 Windows 上的 AMD 显卡加速，因此在 Windows + AMD 显卡环境下，项目会自动退回到 **CPU** 运行  可以先继续运行，但如果 AI 推断、annotation、segmentation 功能报错，就可能和 GPU/驱动有关。  PyTorch 官方也提供 CPU-only 安装方式，但这个项目原安装文档给的是 CUDA 11.8 方案。([pytorch.org](https://pytorch.org/get-started/previous-versions/)) CPU 方案可以尝试，但不能保证完整 AI 功能都正常。

---

## 7. Port '8000' is occupied

If the backend starts it reports:

```text
address already in use
```

You can check which processes are occupying ports:

```bat
netstat -ano | findstr :8000
```

You'll see something like:

```text
TCP    127.0.0.1:8000    ...    LISTENING    12345
```

The final '12345' is PID.  To wrap it up:

```bat
taskkill /PID 12345 /F
```

Then restart:

```bat
python server.py --output_dir "D:\NicheTwin3D\App\NicheTwin3D\NicheTwin3D_Data\StreamingAssets"
```

---

Third, is the backend window open? Full functionality requires the backend to remain running.
