# NicheTwin3D: A universal digital twin paradigm for virtual cell initiative

[![Unity](https://img.shields.io/badge/Unity-2023.1%2B-blue.svg)](https://unity.com/)
[![Python](https://img.shields.io/badge/Python-3.8%2B-green.svg)](https://www.python.org/)
[![Model](https://img.shields.io/badge/Model-Nicheformer-orange.svg)](https://huggingface.co/datasets/www123222/NicheTwin3D)

This system is an interactive spatial transcriptomics digital twin framework based on Unity and deep learning. It combines a high-performance 3D rendering engine with advanced AI models (Nicheformer) to provide researchers with an intuitive platform for exploring cell distribution, gene expression, cell type annotation, and tissue regional segmentation.

## Installation

### 1. Clone Repository & Environment Preparation

```markdown
git clone https://github.com/your-username/NicheTwin3D.git
cd NicheTwin3D
```

### 2. Download Data

**⚠️ IMPORTANT**: Due to their large file size, the model weights and H5AD datasets are NOT directly included in the GitHub repository. Please download them from Hugging Face:

- **Download Link**: [Hugging Face - NicheTwin3D Dataset](https://huggingface.co/datasets/www123222/NicheTwin3D/tree/main). The `data.zip` file in the link contains both the model weights and the datasets.
- **Placement Instructions**:
  - After extracting `data.zip`, please place the extracted model weights and dataset files into the `NicheTwin3D-main\Server` directory of your cloned NicheTwin3D project.

### 3. Python Backend Configuration

First, configure the Nicheformer model architecture by placing the Nicheformer source code inside the `NicheTwin3D-main\Server\Nicheformer` directory.

Next, set up the running environment:

```bash
# Enter the backend directory
cd Assets/Scripts/Server

# Install dependencies
pip install -r requirements.txt

# Start the service
python server.py
```

Upon a successful startup, the backend will run at `http://127.0.0.1:8000`. Meanwhile, it will automatically generate a `unity_cell_data.csv` data file located in the `NicheTwin3D-main\Assets\StreamingAssets` directory. This data file will be required for the subsequent Unity frontend configuration. 

### 4. Unity Frontend Configuration

#### Download Software

**Download Link**: [Hugging Face - NicheTwin3D Dataset](https://huggingface.co/datasets/www123222/NicheTwin3D/tree/main)

The `NicheTwin3D.zip` file in the link contains the compressed application software.

1. First, move the `unity_cell_data.csv` data file generated by the Python backend into the `NicheTwin3D\NicheTwin3D_Data\StreamingAssets` directory of the extracted software package.
2. Directly run **NicheTwin3D.exe** to interact with the visualized results on the frontend.
